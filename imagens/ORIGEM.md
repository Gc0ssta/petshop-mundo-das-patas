# Origem das imagens

Imagens ilustrativas criadas em 10/11/2026 para o Petshop Mundo das Patas com a ferramenta integrada OpenAI Image Generation (imagegen), sem uso da API/CLI. Não são fotografias de produtos reais nem imagens copiadas de terceiros. Os arquivos originais gerados foram copiados para esta pasta, sem edição.

A seguir estão os prompts completos utilizados, preservados para documentar a origem e a intenção de cada imagem.
